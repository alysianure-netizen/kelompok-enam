## 2. Project Title
Ticket Price Calculator

--- 
## 3. Project Description
This is a program that calculates the total price of tickets for an event. The ticket price depends on the visitor's age and total tickets that are purchased.

---
## 4. Objectives
This project is designed to apply the following programming concepts:
- Variables
- Data types
- Operators
- Conditional statements
- Loops
- Algorithms
- JavaScript
---
## 5. Input
The program receives:
- The number of visitors
- The age of each visitor
---
## 6. Process
The program determines the ticket price based on the visitor's age:
- Under 5 years old → Free
- 5-12 years old → $5
- 13-59 years old → $10
- 60 years old or older → $7

The program calculates the total ticket price. If 5 or more tickets are purchased, a 10% discount is applied.

---
## 7. Output
The program displays:
- The ticket price for each visitor
- The total number of tickets
- The total price
- The discount
- The final price after discount
